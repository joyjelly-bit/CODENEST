# Hooked by Phishing: A Gamified Approach to Phishing Awareness

## Project Introduction
Phishing attacks are one of the most common and dangerous cybersecurity threats. This project addresses the need for better awareness and prevention by creating a gamified tool that teaches users how to spot phishing attempts. The tool uses real-world scenarios, offering feedback and points to encourage learning and engagement. By the end of the game, users will have improved their ability to detect phishing threats in emails, websites, and messages.

## Gamification Model

### Scenario-based Levels
Players progress through various levels that simulate different types of phishing attacks:
- **Email Phishing**
- **SMS Phishing (Smishing)**
- **Fake Websites (Pharming)**
- **Social Media Phishing**

### Point System
- Players earn points for correctly identifying phishing attempts.
- Players lose points for incorrect answers.
- The goal is to engage users while reinforcing the learning process.

### Reward System
- As players advance, they unlock:
  - **New Levels**
  - **Special Tools (like "Phishing Detector" gadgets)**
  - **Extra Hints**

## Evaluation Metrics

- **Accuracy**: The percentage of phishing attempts correctly identified by the player.
- **Progression**: The number of levels or challenges completed by the player.
- **Engagement**: Time spent on the game, repeat players, and scores achieved.
- **Feedback Quality**: The effectiveness of the feedback provided after each decision, helping users understand why their choice was correct or incorrect.

## Conclusion
The **Gamified Phishing Awareness Tool** provides an interactive, engaging way to educate users about phishing and improve their ability to recognize phishing attacks. Based on the evaluation metrics, this tool has the potential to become a useful resource for cybersecurity training.

### Future Development
Future development steps could include:
- Adding more advanced phishing attack scenarios.
- Integrating real-time email analysis.
- Making the game available as a **browser extension** or **mobile app** for easier access.
